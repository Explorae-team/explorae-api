# Exploraê - Monorepo (MVP)

Bem-vindo ao repositório unificado do Exploraê!

## 📂 Estrutura de Pastas
- `backend`: API REST (Spring Boot, Java 21, PostgreSQL, JWT).
- `frontend`: Aplicação Web (React/TypeScript).
- `docs`: Documentação geral (requisitos, modelagem).

## 🚀 Como Rodar o Projeto

### Backend
1. Entre na pasta `backend`.
2. Configure o arquivo `.env` (use `.env.example` como base).
3. Execute o comando: `./mvnw spring-boot:run`

### Frontend
1. Entre na pasta `frontend`.
2. (Setup em andamento)

## 🐳 Docker (Desenvolvimento)
Em breve, teremos um `docker-compose.yml` para rodar o banco de dados e as aplicações com facilidade.

## 🤝 Contribuição
Todas as features devem ser enviadas via Pull Request. Para o MVP, as mudanças devem ser feitas de forma atômica, unindo as alterações de Back e Front no mesmo PR quando possível!
