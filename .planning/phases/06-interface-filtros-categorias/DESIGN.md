# DESIGN - Phase 6: Interface de Filtros e Categorias

## 🎨 Conceito Visual: "Explorador Moderno"

O design deve passar a sensação de uma ferramenta de exploração de alta tecnologia, mas acessível.

### 🔍 Search Bar
- **Forma**: Cápsula (pill-shaped).
- **Background**: `rgba(255, 255, 255, 0.05)`.
- **Borda**: `rgba(255, 255, 255, 0.1)`.
- **Sombra**: Neumorphism suave ou elevação mínima.

### 🎭 Filtros
- **Ícones**: Estilo "Outline" para itens inativos, "Solid" para ativos.
- **Destaque**: Uso da cor Primária (#fd6c28) apenas para elementos de foco e botões de ação.

### 📱 Layout do Modal
- **Fundo**: `#00161e` sólido ou com leve blur se for um Bottom Sheet.
- **Divisores**: Linhas finas `rgba(255, 255, 255, 0.05)`.
- **Botões**:
    - **Primário**: Fundo Primário, Texto Branco.
    - **Secundário/Limpar**: Apenas texto ou borda outline.

## 🏃 Animações
- **Modal**: Slide de baixo para cima.
- **Categorias**: Escala leve (1.05x) ao tocar.
