# Identidade Visual: Exploraê

## 🎨 Conceito
**"A jornada é o prêmio."**
O Exploraê transforma cada passo em uma conquista. A marca é vibrante, tecnológica, amigável e recompensadora.

## 🌈 Paleta de Cores (The Adventure Palette)

| Cor | Hex | Significado |
| :--- | :--- | :--- |
| **Laranja Horizonte** | `#FF6B35` | Energia, aventura, entusiasmo. Cor da ação. |
| **Azul Explora** | `#004E64` | Tecnologia, confiança e segurança. |
| **Céu Aberto** | `#00A8E8` | Liberdade e possibilidades da viagem. |
| **Ouro Recompensa** | `#FFD700` | Gamificação, valor e pontos. |
| **Cinza Asfalto** | `#F4F4F9` | Fundo de interface e legibilidade. |

## 🅰️ Tipografia
- **Títulos**: Inter (Extra Bold)
- **Corpo**: Inter (Regular)

## 🏆 Gamificação (Níveis)
- **Bronze**: `#CD7F32`
- **Prata**: `#C0C0C0`
- **Ouro**: `#FFD700`
- **Platina**: `#E5E4E2`
- **Diamante**: Gradiente holográfico

## 📐 Diretrizes de UI (Tailwind Ready)
- **Border Radius**: `rounded-2xl` (16px)
- **Buttons**:
  - Primary: Laranja Horizonte com `shadow-lg`
  - Secondary: Azul Explora com bordas finas
- **Cards**: Fundo branco, bordas sutis e `backdrop-blur`.
